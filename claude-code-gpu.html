Colab GPU (Community) for Orca

Give Claude Code a GPU with Google Colab

Claude Code runs on your laptop, which usually has no GPU. With Colab GPU for Orca, Claude Code starts a Google Colab runtime on your own account, runs the GPU work there and brings the results back, while your code and credentials stay local.

Steps

  1. Install the plugin. In Orca, install Colab GPU (Community) for Orca from the plugin directory.
  2. Sign in with Google. Open the Colab GPU panel, click Sign in with Google and tick the Colab permission on Google's consent page.
  3. Set guardrails. Under Guardrails & CU, pick the GPUs Claude Code may start (for example T4 and L4) and the maximum number of runtimes.
  4. Ask Claude Code for GPU work. For example: “Train this model on a T4 and bring back the checkpoint.” Through the colab-gpu skill it runs orca-colab up --gpu T4, sync, job submit --wait and pull.
  5. Watch and stop. Follow live output in the panel; Claude Code runs orca-colab down when it is done, and idle runtimes stop on their own after 20 minutes.

What Claude Code runs

orca-colab up --gpu T4 --json
orca-colab sync --json
orca-colab job submit --name "Train" --wait --json -- python3 train.py
orca-colab pull checkpoints ./results --json
orca-colab down --json
