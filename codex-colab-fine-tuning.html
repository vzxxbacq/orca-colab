Colab GPU (Community) for Orca

Fine-tune a model with Codex on a Colab GPU

Codex can write a fine-tuning script but cannot run it without a GPU. Colab GPU for Orca lets Codex in Orca start a Colab runtime, run the job with live logs and pull the trained weights back.

Steps

  1. Install and sign in. Install Colab GPU (Community) for Orca in Orca and sign in with Google in its panel.
  2. Allow a larger GPU. Under Guardrails & CU, allow L4 or A100 if your Colab account can use them, and set a monthly compute-unit budget.
  3. Ask Codex to fine-tune. For example: “Fine-tune this model on an L4 with the dataset in data/, then evaluate it.” Codex syncs the workspace and submits the job with orca-colab job submit.
  4. Follow the run. The panel shows the job's live output, the runtime's GPU memory and the estimated compute units used.
  5. Bring the weights home. Codex runs orca-colab pull for the output folder; files arrive byte for byte, then it releases the runtime with orca-colab down.

Tips

  • Have the dataset downloaded on the runtime (for example from Hugging Face) instead of syncing large files from your laptop.
  • Write checkpoints regularly and pull them: Colab runtimes are time-limited.
