Colab GPU (Community) for Orca

Run Google Colab GPUs from the terminal

orca-colab is the command-line tool behind Colab GPU for Orca. It needs only Node.js 20+, prints one JSON object per command for scripts and agents, and talks to Colab over HTTPS, with no notebook, SSH or VPN.

Steps

  1. Sign in once. Run orca-colab auth login; your browser opens Google's consent page. Tick the Colab permission.
  2. Start a runtime. orca-colab up --gpu T4 --json starts or reuses a Colab runtime and reports its GPU.
  3. Send your code. orca-colab sync --json uploads the current folder, honouring .gitignore and .colabignore.
  4. Run work. orca-colab run --json -- nvidia-smi for quick commands, or orca-colab job submit --wait --json -- python3 train.py for tracked jobs with logs.
  5. Get results and stop. orca-colab pull outputs ./results --json downloads results; orca-colab down --json releases the runtime.

Install

No install step is needed: run it with npx using the pinned command from the latest release. Agents can learn it from the skill: npx skills add vzxxbacq/orca-colab.
