Step 2 · Tailscale Auth Key & SSH Key
Required
Each Colab GPU VM uses this key to join your private tailnet so Orca can reach it over direct SSH.
How do I get a Tailscale / Headscale Auth Key?
• Official Tailscale: Open Settings → Keys → Generate auth key (enable Reusable + Ephemeral). Starts with tskey-auth-...
• Self-hosted Headscale: Generate a pre-auth key on your Headscale server (e.g. headscale preauthkeys create --reusable --ephemeral -u <user>) and fill in your Login Server URL below.
